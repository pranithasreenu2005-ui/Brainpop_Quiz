# 🧠 DevQuiz - Interactive Web Quiz Application

A lightweight, responsive web-based quiz app built using core web technologies (HTML5, CSS3, and JavaScript). The application presents interactive multiple-choice questions, tracks score in real-time, and provides visual feedback for correct and incorrect answers.

## ✨ Features

**Dynamic Question Loading**: Questions and choices are rendered dynamically using JavaScript DOM manipulation.
**Instant Visual Feedback**: Selected options highlight green for correct answers and red for incorrect choices.
**Score Calculation**: Automatically keeps track of the user's score throughout the quiz.
**Fully Responsive**: Clean, centered UI that adapts seamlessly across mobile and desktop browsers.
**Zero External Dependencies**: Built entirely with pure vanilla HTML, CSS, and JS—no frameworks required.

## 🛠️ Built With

* **HTML5**: Structural markup of the application.
* **CSS3**: Layout styling, button feedback, and responsive layout design.
* **JavaScript (ES6+)**: Core application logic, event listeners, state tracking, and dynamic element rendering.
